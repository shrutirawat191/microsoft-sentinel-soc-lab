# 1. Azure and Microsoft Sentinel Setup

## Objective
Prepare the Azure resources needed for a Sentinel lab.

## Procedure
1. Create or identify the Azure resource group.
2. Create or identify the Log Analytics workspace (LAW).
3. Enable Microsoft Sentinel on the workspace.
4. Confirm that the workspace and Sentinel instance are accessible.
