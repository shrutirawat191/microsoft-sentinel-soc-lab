# 6. Automation and Workbooks

## Objective
Document how Sentinel playbooks, Azure Logic Apps, and Workbooks can support incident response and monitoring.

## Automation checklist
- Identify the trigger and incident/event type.
- Define the workflow and any notification/remediation action.
- Use least-privilege permissions and approved connectors.
- Test safely in a controlled lab.
- Record the run history and outcome.

## Workbook checklist
- Select a relevant data source and query.
- Choose useful visualizations for SOC monitoring.
- Validate that the displayed metrics match the underlying query results.
