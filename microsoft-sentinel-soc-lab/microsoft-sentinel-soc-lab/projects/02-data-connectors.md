# 2. Data Connectors

## Objective
Explore data connectors that bring security and platform telemetry into Microsoft Sentinel.

## Procedure
1. Open the Sentinel data connectors or Content Hub experience.
2. Identify the relevant connector for the data source.
3. Follow the connector's prerequisites and configuration flow.
4. Generate or wait for test events, then verify ingestion in the workspace.

## Validation
A connector being enabled does not alone prove data is arriving. Confirm that expected events appear in the relevant table and record the time range checked.

## Evidence to add
- Connector configuration page.
- Query results showing ingested events, with sensitive data redacted.
