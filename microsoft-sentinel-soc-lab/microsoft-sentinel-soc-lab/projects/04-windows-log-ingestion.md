# 4. Windows Log Ingestion

## Objective
Connect Windows event data to the Log Analytics workspace and make it available for Sentinel investigation.

## Procedure
1. Identify the Windows log collection method supported by your lab setup.
2. Configure the required agent/connector and data collection settings.
3. Generate safe test activity on the lab endpoint.
4. Query the workspace to confirm that events arrive.
5. Record the table names, time range, and sample event types.

## Evidence to add
- Sanitized collection configuration.
- Query output confirming events were ingested.
